# Changelog

## 0.1.0 (2026-05-28)

### Features

- **Stage 2: Contract Publishing** — Publish Swagger/OpenAPI JSON to YApi with smart merge strategies
- **Stage 3: Frontend Code Gen** — Generate TypeScript interfaces, axios/fetch clients, MSW handlers, Zod validators from YApi
- **Stage 4: Backend Scaffold** — Generate Java (Spring Boot), Go (Gin), Node.js (Express) controllers and DTOs from YApi
- **CLI** — Full-featured CLI: init, run, publish, generate, doctor, config
- **Pipeline Engine** — Extensible pipeline orchestration with lifecycle hooks
- **Monorepo** — pnpm workspace with shared types, @yapi-flow/core, @yapi-flow/publish, @yapi-flow/generator, @yapi-flow/cli
